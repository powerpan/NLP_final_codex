## 已知實作限制

- CLI 採單程序排他鎖，沒有線上多人登入與即時控制通道。
- 記憶是有來源的局部經驗重用，尚未證明會提升模型表現；沒有 Agent Evolution 結論。
- 記憶體 fixture 不能執行程式。持久 Docker 卷不自動回收，也沒有硬磁碟配額。
- task 內 unittest 不是隔離的隱藏評測；範例外部套件只驗證文字與產物契約。
- 未知副作用採停住並核對的策略；沒有端到端 exactly-once 保證。
- 工具 batch 為序列執行，task 之間有限並行；網頁資料有確定性的預覽／保存引用投影，沒有模型生成的歷史壓縮。保留 reasoning 與工具配對後仍超限就報錯。
- HTTPS 請求使用背景執行緒，取消不保證遠端請求立即停止或不計費。
